Paso 2 📊 ¿Qué es un diagrama de flujo?

Es una representación gráfica de un algoritmo o proceso, donde cada paso se dibuja con un símbolo y se conectan con flechas.

Sirve para mostrar qué pasos se hacen, en qué orden y qué decisiones se toman, sin necesidad de leer todo un programa en código.

🔑 Tres palabras clave
  • Símbolo: cada figura representa una acción específica.
  • Flecha: indica el orden en que se ejecutan los pasos.
  • Sentido: se lee de arriba hacia abajo (y de izquierda a derecha).

Importante: el diagrama de flujo se dibuja antes de programar. Primero piensas el proceso, luego lo dibujas y por último lo conviertes en código.

Paso 3 🎯 ¿Para qué sirve?

Un diagrama de flujo sirve para explicar, ordenar y comunicar cualquier proceso.

💼 4 usos concretos
  • 1. Enfatizar procesos 📋 — describe un procedimiento paso a paso de forma clara.
  • 2. Representar algoritmos 💻 — es la base para programar en cualquier lenguaje.
  • 3. Documentar sistemas 📚 — explica cómo funciona un sistema a quien no lo programó.
  • 4. Detectar errores 🔍 — si falta una flecha o un símbolo, el error queda visible.

Un diagrama bien hecho evita confusiones: cualquier persona puede leerlo y entender el proceso aunque no sepa de programación.

Paso 4 🔷 Los símbolos básicos

Cada figura tiene un significado fijo. Estos son los 6 que vas a usar siempre.

SímboloNombre¿Cuándo se usa?
Elipse / Óvalo Inicio y Fin. Solo hay uno de cada. Todo diagrama empieza y termina aquí.
Rectángulo Proceso: cualquier operación, cálculo o asignación. Es el símbolo que más se usa.
Rombo / Diamante Decisión: una pregunta que solo puede ser Sí/No. Siempre tiene dos salidas.
Paralelogramo Entrada o Salida: leer datos del usuario o mostrar un resultado en pantalla.
Documento Imprimir o guardar un documento: una factura, un acta, un informe.
Conector Une dos partes lejanas del diagrama para que no se cruce con líneas.
⚡ Regla rápida para recordarlos

Óvalo = principio y fin · Rectángulo = hacer algo · Rombo = decidir · Paralelogramo = leer o mostrar · Documento = imprimir · Círculo = conectar.

Paso 5 ➡️ Reglas para dibujar bien

Un diagrama correcto sigue estas 8 reglas. Si las cumples, tu diagrama se entiende.

✅ Las 8 reglas
  • 1. Todo diagrama tiene un solo Inicio y un solo Fin.
  • 2. El flujo va de arriba hacia abajo; las flechas nunca apuntan hacia atrás, salvo en un ciclo.
  • 3. El rombo (decisión) tiene exactamente dos salidas: Sí/No o Verdadero/Falso.
  • 4. Las dos salidas de una decisión se etiquetan (Sí, No) para saber cuál es cuál.
  • 5. No se dibujan líneas cruzadas; si se cruzan, usa un conector.
  • 6. Cada símbolo debe tener una sola entrada y una sola salida (salvo el Inicio y el Fin).
  • 7. Los textos van dentro del símbolo, corto y sin punto final.
  • 8. Un ciclo (flecha que vuelve hacia atrás) significa que el proceso se repite.

Truco: si tu diagrama no tiene ningún rombo, es un proceso secuencial (los pasos siempre son iguales).

Paso 6 🔍 Errores comunes

Estos son los errores que más se cometen al hacer un diagrama. Evítalos.

❌ Error✅ Cómo corregirlo
Dos o más rombos con más de 2 salidasDivide la decisión en dos rombos, uno después del otro.
Flechas cruzadas por todo el diagramaUsa conectores (círculos con letras o números).
Un rombo que dice "si el número es par o impar"Una decisión solo puede ser Sí/No. Deja la decisión para una sola condición.
Sin símbolo de Inicio o sin FinTodo diagrama siempre empieza en un óvalo y termina en otro.
Ciclo sin flecha de regresoSi algo se repite, dibuja la flecha de vuelta hacia la condición.
Textos larguísimos dentro del símboloDivide la idea en dos rectángulos o acórtala.
🧪 Antes de entregar, pregúntate

1) ¿Tiene Inicio y Fin? · 2) ¿Los rombos tienen 2 salidas etiquetadas? · 3) ¿Las flechas se leen de arriba hacia abajo? · 4) ¿Hay líneas cruzadas?

Paso 8 🔢 Ejemplo 2 — ¿Par o impar? (10 números)

Introduce el ciclo: la flecha que vuelve hacia atrás hace que el proceso se repita. 11 pasos.

🔄 Tipo: CICLO (repetir) · Símbolos: óvalo, rombo, paralelogramo · 11 pasos
📖 Cómo se lee
  1. Inicio del programa.
  2. Se declara el total de números a procesar (10) y el contador en 1.
  3. Se pregunta: ¿el contador es menor o igual al total? Si es No, se termina.
  4. Se lee un número del usuario.
  5. Se calcula el residuo de dividirlo entre 2.
  6. Se pregunta: ¿el residuo es 0? Sí → es PAR. No → es IMPAR.
  7. Se muestra el número con su resultado.
  8. Se aumenta el contador en 1.
  9. La flecha vuelve a la pregunta del paso 3: el ciclo se repite.
  10. Cuando el contador supera el total, el proceso finaliza.
💡 Lección clave del ciclo

La flecha que sube hacia atrás es la que convierte un proceso en repetitivo. Si la quitas, el algoritmo solo haría una vuelta. Recuerda: condición → proceso → volver a la condición.

📝 Pseudocódigo

PROCESO ParOImpar
  Declarar total ← 10
  Declarar contador ← 1

  MIENTRAS contador <= total HACER
    Leer número
    residuo ← número mod 2
    SI residuo = 0 ENTONCES
      Mostrar "es PAR"
    SINO
      Mostrar "es IMPAR"
    FIN_SI
    contador ← contador + 1
  FIN_MIENTRAS
FIN

💻 Código PSeInt

Algoritmo par_impar
    Definir total Como Entero
    Definir contador Como Entero
    Definir numero Como Entero
    Definir residuo Como Entero

    total <- 10
    contador <- 1

    Mientras contador <= total Hacer
        Escribir "Numero ", contador, ": "
        Leer numero
        residuo <- numero mod 2
        Si residuo == 0 Entonces
            Escribir numero, " es PAR"
        SiNo
            Escribir numero, " es IMPAR"
        FinSi
        contador <- contador + 1
    FinMientras
Fin

Paso 9 📊 Ejemplo 3 — Promedio de 5 notas

El más completo: ciclo + dos decisiones + validación de datos. 14 pasos.

🔄 Tipo: CICLO + DECISIÓN · Símbolos: todos · 14 pasos
📖 Cómo se lee
  1. Inicio del programa.
  2. Se declaran las variables: notas = 5 y contador = 1.
  3. Se inicializa la sumatoria en 0.
  4. Se pregunta: ¿el contador es menor o igual a 5? Si No, se sale del ciclo y se pasa al cálculo del promedio.
  5. Se lee una nota.
  6. Se pregunta: ¿la nota está entre 0 y 5? Si No, se asigna 0 a esa nota.
  7. Se acumula la nota en la sumatoria.
  8. Se aumenta el contador en 1.
  9. La flecha vuelve al paso 4: se repite por cada nota.
  10. Cuando terminan las 5 notas, se calcula el promedio (sumatoria ÷ 5).
  11. Se pregunta: ¿el promedio es mayor o igual a 3.0?
  12. Sí → se muestra "APROBÓ". No → se muestra "REPROBÓ".
  13. Se termina el programa.
💡 Fíjate en esto

La validación (paso 6) protege al programa de datos inválidos. Y el ciclo es lo que le permite leer 5 notas sin escribir 5 veces las mismas instrucciones. Esa es la ventaja real del ciclo.

📝 Pseudocódigo

PROCESO PromedioDeNotas
  Declarar notas ← 5, contador ← 1, sumatoria ← 0

  MIENTRAS contador <= notas HACER
    Leer nota
    SI nota < 0 O nota > 5 ENTONCES
      nota ← 0
    FIN_SI
    sumatoria ← sumatoria + nota
    contador ← contador + 1
  FIN_MIENTRAS

  promedio ← sumatoria / notas

  SI promedio >= 3.0 ENTONCES
    Mostrar "APROBÓ con promedio ", promedio
  SINO
    Mostrar "REPROBÓ con promedio ", promedio
  FIN_SI
FIN

💻 Código PSeInt

Algoritmo promedio_notas
    Definir notas Como Entero
    Definir contador Como Entero
    Definir nota Como Real
    Definir sumatoria Como Real
    Definir promedio Como Real

    notas <- 5
    contador <- 1
    sumatoria <- 0

    Mientras contador <= notas Hacer
        Escribir "Nota ", contador, ": "
        Leer nota
        Si nota < 0 o nota > 5 Entonces
            Escribir "Nota invalida, se toma como 0"
            nota <- 0
        FinSi
        sumatoria <- sumatoria + nota
        contador <- contador + 1
    FinMientras

    promedio <- sumatoria / notas

    Si promedio >= 3.0 Entonces
        Escribir "APROBO con promedio ", promedio
    SiNo
        Escribir "REPROBO con promedio ", promedio
    FinSi
Fin

Paso 10 🔣 Ejemplo 4 — Calculadora de áreas

El más avanzado: menú interactivo con 3 opciones y regreso al menú. 18 pasos.

🔣 Tipo: MENÚ / CICLO · 4 decisiones · 18 pasos
📖 Cómo se lee
  1. Inicio del programa.
  2. Se muestra el menú con las 4 opciones.
  3. Se lee la opción que elige el usuario.
  4. Se pregunta: ¿la opción es 4 (salir)? Sí → el programa termina.
  5. Se pregunta: ¿la opción es 1? Sí → se calcula el área del cuadrado.
  6. Se lee el lado → área = lado × lado → se muestra el resultado.
  7. Flecha de regreso: vuelve al menú para pedir otra opción.
  8. Se pregunta: ¿la opción es 2? Sí → se calcula el área del triángulo.
  9. Se lee base y altura → área = (base × altura) / 2 → se muestra.
  10. Flecha de regreso: vuelve al menú.
  11. Se pregunta: ¿la opción es 3? Sí → se calcula el área del círculo.
  12. Se lee el radio → área = 3.1416 × radio² → se muestra.
  13. Flecha de regreso: vuelve al menú.
  14. Si ninguna condición se cumplió, se muestra "Opción no válida" y vuelve al menú.
  15. Se termina el programa.
💡 Dos trucos que ahorran trabajo
  • El ciclo (flechas de regreso) evita repetir "mostrar menú" y "leer opción" tres veces.
  • La decisión en cascada (preguntar 1, luego 2, luego 3) evita escribir 4 rombos separados.

📝 Pseudocódigo

PROCESO CalculadoraDeAreas
  REPETIR
    Mostrar "1. Cuadrado  2. Triángulo  3. Círculo  4. Salir"
    Leer opción
    SI opción = 1 ENTONCES
      Leer lado
      área ← lado * lado
      Mostrar "Área del cuadrado: ", área
    SINO
      SI opción = 2 ENTONCES
        Leer base, altura
        área ← (base * altura) / 2
        Mostrar "Área del triángulo: ", área
      SINO
        SI opción = 3 ENTONCES
          Leer radio
          área ← 3.1416 * radio^2
          Mostrar "Área del círculo: ", área
        SINO
          SI opción = 4 ENTONCES
            Mostrar "Saliendo"
          SINO
            Mostrar "Opción no válida"
          FIN_SI
        FIN_SI
      FIN_SI
    FIN_SI
  HASTA QUE opción = 4
FIN

Paso 11 🛠️ Cómo hacer tu propio diagrama

El método exacto en 6 pasos, para cuando te pidan dibujar uno.

🧭 Método de los 6 pasos
  1. 1. Lee el problema. Escribe con tus palabras qué debes lograr.
  2. 2. Identifica la entrada. ¿Qué datos te da el usuario? (lecturas / paralelogramos)
  3. 3. Identifica la salida. ¿Qué debes mostrar al final? (paralelogramos)
  4. 4. Lista las operaciones. Escribe los pasos intermedios como rectángulos, en orden.
  5. 5. Marca las decisiones. ¿Hay algo que sea Sí/No? → rombos. ¿Algo se repite? → ciclo.
  6. 6. Conecta y revisa. Une con flechas de arriba hacia abajo, pon Inicio y Fin, y verifica las 8 reglas.
🧪 Ejercicio rápido para practicar

Dibuja el diagrama de: "Pedir una pizza por teléfono". Usa al menos 8 pasos y 2 decisiones (tamaño y bebida).

Dibuja el diagrama de: "Calcular el total de una compra con descuento". Usa al menos 10 pasos y 1 decisión (si el total supera $50.000).

Paso 15 🖥️ Plan B — en PowerPoint o Paint

Si no tienes internet en el aula, haz tu diagrama con estos programas. El resultado es el mismo.

🖥️ En PowerPoint (recomendado)
  1. Abre PowerPoint y crea una diapositiva en blanco.
  2. Ve a Insertar → Formas. Ahí están todas las figuras.
  3. Elige Óvalo para el Inicio y el Fin.
  4. Elige Rectángulo para cada proceso.
  5. Elige Rombo (diamante) para cada decisión.
  6. Elige Paralelogramo para leer datos o mostrar resultados.
  7. Elige Forma de flecha y úsala para unir los pasos, siempre hacia abajo.
  8. Haz clic dentro de cada figura y escribe el texto.
  9. Cambia el color del borde: clic derecho sobre la forma → Contorno de forma.
  10. Guarda como .pptx y también expórtalo a PDF o imagen.
🎨 En Paint
  1. Abre Paint y crea un lienzo vertical (tamaño completo), no cuadrado.
  2. En Herramientas de formas, elige la figura y dibújala arrastrando.
  3. Para el texto dentro, usa la herramienta A o Texto.
  4. Para las flechas, usa el lápiz con grosor grueso y pon la punta de la flecha con la mano al final.
  5. Si te equivocas, usa Ctrl + Z para deshacer.
  6. Guarda como .png desde Archivo → Guardar como.
✅ Lista de chequeo — revisa antes de entregar
  • ☐ Tiene Inicio y Fin (dos óvalos).
  • ☐ Tiene mínimo 10 pasos.
  • ☐ Tiene al menos 2 rombos de decisión con sus dos salidas (Sí/No).
  • ☐ Las dos salidas de cada rombo están etiquetadas.
  • ☐ Si algo se repite, tiene la flecha de regreso (ciclo).
  • ☐ Las flechas se leen de arriba hacia abajo.
  • ☐ No hay líneas cruzadas.
  • ☐ Usé paralelogramo para leer datos o mostrar resultados.
  • ☐ El texto está dentro de cada figura y es corto.
  • ☐ Se entiende el proceso sin que nadie te lo explique.
🏆 Criterios para que tu diagrama quede bien
  • Ordenado: los símbolos alineados y con el mismo tamaño.
  • Claro: el texto se lee sin esfuerzo.
  • Completo: no le falta ningún paso del proceso real.
  • Correcto: cada símbolo usado para lo que corresponde.
