# Votá, Parcero 🗳️

Módulo educativo web sobre participación ciudadana y el voto en Colombia, diseñado para el taller de **grado once**.

El sitio tiene estructura didáctica: objetivos de aprendizaje, cinco unidades con definiciones y datos, actividades de taller, quiz interactivo de evaluación y glosario.

## Contenido del módulo

1. **Unidad 1 · ¿Qué es el voto?** — Concepto, marco constitucional, organizadores electorales y qué cargos se eligen.
2. **Unidad 2 · ¿Por qué votar?** — Argumentos y datos sobre el poder del voto joven.
3. **Unidad 3 · El camino del voto** — Paso a paso: antes, durante y después de la jornada electoral.
4. **Unidad 4 · Métodos de votación** — Tarjetón, voto en blanco, listas abiertas y cerradas, voto electrónico y exterior.
5. **Unidad 5 · Requisitos y reglas** — Documentos válidos, errores que anulan el voto y beneficios del certificado.
6. **Actividades** — 6 dinámicas para hacer en el taller (simulación de votación, debate, etc.).
7. **Quiz** — 10 preguntas interactivas con retroalimentación y puntaje final.

## Tecnologías

Sitio estático con HTML, CSS y JavaScript puro (sin frameworks). Alojado en GitHub Pages.

## Despliegue local

Abre `index.html` directamente en el navegador, o sirve la carpeta con cualquier servidor estático:

```bash
python -m http.server 8000
```
