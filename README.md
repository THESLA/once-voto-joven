# Votá, Parcero 🗳️

Guía web para jóvenes sobre por qué votar en Colombia, cómo funcionan los métodos de votación y todo lo que se necesita saber para ejercer el derecho al voto. Material para el taller de participación ciudadana del grado once.

## Contenido

- **¿Por qué votar?** — Razones y datos que muestran el poder del voto joven.
- **¿Cómo voto?** — Paso a paso: cédula, inscripción, puesto de votación y día de la jornada.
- **Métodos de votación** — Tarjetón presencial, voto en blanco, listas abiertas y cerradas, voto electrónico y voto en el exterior.
- **Lo que debes saber** — Requisitos, documentos válidos, errores que anulan el voto, beneficios del certificado electoral.
- **Mitos y realidades** — Respuestas a las dudas más comunes.
- **Glosario** — Términos clave del mundo electoral.

## Tecnologías

Sitio estático con HTML, CSS y JavaScript puro (sin frameworks). Alojado en GitHub Pages.

## Despliegue local

Abre `index.html` directamente en el navegador, o sirve la carpeta con cualquier servidor estático:

```bash
python -m http.server 8000
```
